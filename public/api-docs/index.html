Solmint Public API

مجموعه APIهای عمومی و فقط‌خواندنی سولمینت برای داده‌های سولانا، تحلیل توکن، تحلیل کیف پول و محتوای سایت.

مشخصات OpenAPI 3.1 · API Catalog

/api/articles

فهرست مقالات منتشرشده عمومی. داده‌های مدیریت و draft از مسیر عمومی ارائه نمی‌شوند.

GET https://solmint.ir/api/articles

/api/solana/status

داده وضعیت و متریک‌های عمومی شبکه Solana که در سایت مصرف می‌شوند.

GET https://solmint.ir/api/solana/status

/api/tools/solana-token

بررسی read-only یک Mint روی شبکه Solana، شامل Token Program، supply، authorities و Token-2022 extensions.

GET https://solmint.ir/api/tools/solana-token?mint=<MINT>&mode=token

/api/tools/token-risk

تحلیل explainable و rule-based ریسک توکن بر اساس داده‌های on-chain و market context.

GET https://solmint.ir/api/tools/token-risk?mint=<MINT>

/api/tools/market-context

داده بازار DEXها برای یک Mint، شامل liquidity، volume، buys/sells و pairهای مشاهده‌شده.

GET https://solmint.ir/api/tools/market-context?mint=<MINT>

/api/wallet/analyze

تحلیل read-only یک آدرس عمومی Solana. هرگز seed phrase، private key یا credential ارسال نکنید.

GET https://solmint.ir/api/wallet/analyze?address=<PUBLIC_ADDRESS>

Health

GET https://solmint.ir/api/health

این APIها برای داده عمومی طراحی شده‌اند و جایگزین audit امنیتی یا توصیه سرمایه‌گذاری نیستند.
